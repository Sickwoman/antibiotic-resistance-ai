# results/metrics/v2.0

**`null_simulation.json` is synthetic evidence, not a Version 2.0 result.** It was produced by
`scripts/v20_null_simulation.py` from simulated scores with fixed seeds, before any MARISMa file was downloaded, to
support the statistical review in amendments A and B of `docs/v2.0_marisma_plan.md`.
- It contains no MARISMa or DRIAMS value.
- It covers null rejection rates of candidate primary tests and power under stated assumptions.

Version 2.0's own outputs will be written to this folder only after the pre-registration is approved and the study is
run. Each will be named so it cannot be mistaken for this file.
