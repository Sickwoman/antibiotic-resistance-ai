# Version 1.1 tables: *E. coli* + ceftriaxone (`ecoli_ceftriaxone`)

Generated by `scripts/second_antibiotic_report.py` from the reports of the Version 1.1 runs, the append-only test log and the stored test probabilities; nothing here is typed by hand, and nothing was scored to make it. Plan: `docs/v1.1_ceftriaxone_plan.md` (protocol amendment 8). Research prototype, not a diagnostic: these are statements about a laboratory label, not advice about any patient.

## What the reader must know first

- **The pair does not meet the project's pair-selection rule on its cohort:** 428 resistant spectra at DRIAMS-A against a minimum of 500. It was run as the benchmark antibiotic named in Version 0.1, not as a pair the rule selected.
- **The cohort is isolates with both a ciprofloxacin and a ceftriaxone result.** 93 isolates with only a ceftriaxone result are in no split: 27 of them resistant (29.0 %, against 10.2 % in the cohort). Nothing here is claimed for them.
- **These spectra were scored before, for ciprofloxacin.** Their ceftriaxone labels had never been used by any model, threshold or choice (amendment 8, point 2).
- **The threshold is coarse:** it was set on a validation part with 34 resistant spectra, so one spectrum moves validation sensitivity by 2.9 points. Threshold-dependent numbers are secondary.
- Intervals are 95 % patient-group bootstrap intervals. "Not demonstrated" is never "no difference".

## The published reference point (descriptive only)

Weis et al. (2022) report AUROC 0.74 for E. coli + ceftriaxone at DRIAMS-A (LightGBM). It lies **inside** arm T's interval (0.604–0.818). Their cohort, split and exclusions differ from this project's, so this is a reference point, not a comparison: nothing here "matches" or "beats" it.

Reference: Weis C, Cuénod A, Rieck B, et al. Direct antimicrobial resistance prediction from clinical MALDI-TOF mass spectra using machine learning. Nat Med 2022;28:164-174. doi:10.1038/s41591-021-01619-9. Checked against the abstract (PMID 35013613) and the authors' code (BorgwardtLab/maldi_amr) before this table was first generated.
