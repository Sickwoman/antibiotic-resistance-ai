## Why this study

- **Independence.** MARISMa comes from a different institution, country and period (Madrid, 2018–2024) than any data
  this project has used (Swiss, 2015–2018). No earlier version touched it.
- **Nothing is refitted.** The two models are frozen exactly as saved, so the question is the cleanest one available:
  does the ranking learned at DRIAMS-A carry to another hospital?
- **Two antibiotics.** They test whether the conclusion of the V0.1–V1.4 cycle, modest ranking at one site, holds
  outside it, for each antibiotic.

## Known limitations, stated before anything is run

1. **No patient linkage.** MARISMa's descriptor says patient information "was completely removed, and a unique
   identifier per bacteria was kept". Repeat isolates from one patient may therefore enter as independent units, and
   isolate-level intervals may be too narrow. This deviates from the report's requirement of patient linkage across
   time. The owner accepted it on 2026-10-02, and it must be stated with every result.
2. **The breakpoint standard is not stated** in the documentation, and the period spans EUCAST's 2019 redefinition of
   "I". Interpretations are taken as reported. The primary analysis counts I as resistant, and an I-excluded
   sensitivity analysis is run (endpoint 6).
3. **Whether the *E. coli* isolates have ciprofloxacin and ceftriaxone results is not confirmed** by the
   documentation. Step 2's schema check decides it, without reading any value.
4. **Instruments and format differ.** MARISMa's spectra were acquired on a Bruker BT Smart MALDI Biotyper and are
   stored in Bruker raw format, which the pipeline has never read. A reader error could look like a transfer failure,
   so the reader is verified on spectra alone before any label is read (step 3).
5. **Transfer is tested as a whole.** Site, country, instrument, period and laboratory practice change together, so a
   failure cannot be attributed to any one of them.
6. **The cut-offs were set on DRIAMS-A validation data**, and the 0.90 sensitivity target already failed on new data
   in V0.1–V1.4. Threshold results are secondary.
7. **Others have analysed MARISMa** with their own models. Their results have not been read and play no part here.

## Cohort (rules fixed now; applied to metadata only, never to labels)

- **Species:** *E. coli* isolates, by MARISMa's species field.
- **Years:** all, 2018–2024.
- **Sample source:** clinical isolates only, by analogy with the DRIAMS HospitalHygiene exclusion.
  - Sources that are screening or colonisation samples are excluded.
  - The exact list of excluded source values is fixed in a dated addendum to this plan. It is written after reading the
    distinct values of the source field (metadata, no labels), and before step 4.
  - If the field cannot separate screening samples, all sources are kept, and that is reported.
- **One spectrum per isolate:** the first biological replicate (lowest folder number), and within it the first
  technical replicate (lowest folder number) that passes the reader's checks. The rule is deterministic and uses no
  label.
- **Reader failures:** spectra that are unreadable, lack calibration, are empty, or do not cover 2,000–20,000 Da are
  excluded and counted.
- **Missing results:** an isolate without an interpretation for an antibiotic is excluded from that antibiotic's
  analysis only. MIC values without an interpretation are not converted, because no breakpoint standard is stated.

## Method

1. **Reader.** A new reader for Bruker raw spectra converts each spectrum to (m/z, intensity) using the calibration
   stored with it. It is tested on fixtures. On the cohort it must give a strictly increasing m/z axis covering
   2,000–20,000 Da; a failure excludes that spectrum (Cohort) and is counted.
2. **Features.** The frozen, stateless pipeline turns each spectrum into the 6,000 features. Nothing learned is
   refitted; each model's pipeline applies its own fitted steps.
3. **Spectra-only checks before labels.** Report the distribution of each MARISMa *E. coli* spectrum's correlation
   with the mean DRIAMS-A *E. coli* training spectrum. This is descriptive: it shows the instrument shift, but it is not
   a gate.
4. **Scoring.** Each frozen model scores its antibiotic's cohort once. The thresholds and the zone are applied as
   frozen.

## Endpoints, and what may be said (fixed now)

These apply to each antibiotic: ciprofloxacin with M-cip, and ceftriaxone with M-cro.

1. **Primary.**
   - **The estimate:** AUROC with a 95 % percentile interval from 2,000 isolate-level bootstrap resamples (seed 42).
     PR-AUC is reported beside it, with its no-skill level, the prevalence.
   - **The test:** one-sided bootstrap p = (1 + number of resamples with AUROC ≤ 0.5) / 2,001.
   - **The correction:** Holm over the two p-values.
   - **The claim:** "ranking transfers to MARISMa" may be said for an antibiotic only if its Holm-adjusted p is below
     0.05. Otherwise the result is "transfer not demonstrated", never "no transfer".
2. **The gap, a key secondary.** Internal AUROC minus MARISMa AUROC, with a 95 % interval from independent
   resamples, as Version 0.7 computed gaps.
   - The internal side is each model's stored `random` test probabilities from DRIAMS-A (M-cip: 856 spectra, 197
     resistant; M-cro: 856, 79). They are not re-scored, and are used only after they reproduce the logged AUROC.
   - "Gap demonstrated" only if the interval excludes 0; never "no gap".
3. **Threshold results, secondary.** Sensitivity, specificity and precision at the frozen cut-off, each with an
   interval. Sensitivity is compared with the 0.90 research target, which is not a clinical standard.
4. **Probabilities, secondary and descriptive.** The Brier score against predicting the base rate, and the calibration
   intercept and slope. No recalibration is applied.
5. **The zone (M-cip only), secondary.** NPV and coverage of the frozen confident-susceptible zone. Both historical
   readings are reported:
   - "met" if the point estimate is ≥ 0.95 (Version 0.8's rule, which decides);
   - "not rejected" if the interval covers 0.95 (Version 0.7's rule).
6. **Sensitivity analyses, pre-specified and executed whatever the primary result:**
   - I excluded;
   - all sample sources, if any were excluded;
   - by period (2018–2019, 2020–2021, 2022–2024), descriptive;
   - by sample-source group, descriptive.
7. **Minimum numbers.** A primary reading is confirmatory only if the antibiotic's cohort has at least 50 resistant
   and 50 susceptible isolates. Otherwise its results are descriptive, and its Holm input is p = 1, so it can be
   rejected under no circumstances.
8. **Completion.** Version 2.0 is complete when it has been run and reported, whatever the result. A failure to
   transfer is a result.

## Sample-size justification (from stated assumptions; no MARISMa count has been seen)

The external AUROC's standard error follows Hanley & McNeil (1982, *Radiology* 143(1):29–36,
`doi:10.1148/radiology.143.1.7063747`), assuming AUROC 0.70.

| Resistant isolates | Susceptible: same number | 4 × | 9 × |
|---|---|---|---|
| 50 | ±0.102 | ±0.087 | ±0.084 |
| 100 | ±0.072 | ±0.062 | ±0.059 |
| 200 | ±0.051 | ±0.044 | ±0.042 |
| 400 | ±0.036 | ±0.031 | ±0.030 |

The values are 95 % half-widths.

- **Power to show AUROC > 0.5** (one-sided α 0.025, Holm's first step), with 50 resistant and 200 susceptible
  isolates: 0.906 if the true AUROC is 0.65, and 0.994 if it is 0.70. The minimum of 50 per class is therefore
  adequate for the primary endpoint.
- **The gap is less precise.** The internal intervals imply standard errors of about 0.0283 (ciprofloxacin) and
  0.0546 (ceftriaxone). With 100 resistant and 400 susceptible external isolates, the gap's 95 % half-width would be
  about 0.083 and 0.123. Only large gaps can be demonstrated, especially for ceftriaxone, and this is stated now.

### A3. The primary test

**Supersedes:**
- endpoint 1: "isolate-level bootstrap resamples", "The test", "The correction" and "The claim";
- the resampling of the gap endpoint's external side.

**Review of the earlier proposal.** The plan proposed p = (1 + number of resamples with AUROC ≤ 0.5) / 2,001, over
bootstrap resamples of the observed isolates. That has two problems:
1. **It does not resample under the null hypothesis.** Hall & Wilson (1991) give two guidelines for bootstrap tests:
   resample in a way that reflects the null hypothesis, and use a pivotal statistic. This p-value does neither. It is
   the tail of the observed AUROC's bootstrap distribution, so its validity rests on the percentile interval's
   one-sided coverage, which is only approximate.
2. **The formula belongs to a different kind of test.** (1 + b) / (m + 1) is the right p-value for Monte Carlo tests
   whose resamples are drawn under the null, such as permutation tests (Phipson & Smyth 2010). It carries no such
   guarantee for resamples of the observed data.

**Synthetic check.** `scripts/v20_null_simulation.py` (seed 42; output `results/metrics/v2.0/null_simulation.json`)
used no research data. It measured the rejection rate under four null scenarios, all at a one-sided nominal level of
0.025:
- **Repetitions:** 4,000 per cell for the three analytic tests (Monte Carlo standard error 0.0025). For the two
  bootstrap tests, 1,000 per cell, each with 1,000 resamples (standard error 0.0049).
- **Scenarios:**
  - **identical:** both classes share one continuous score distribution;
  - **heavy ties:** both classes share 8 distinct score values;
  - **unequal spread:** the distributions differ, but AUROC is exactly 0.5;
  - **clustered:** an assumed mean of 2 isolates per patient, one resistance status per patient, and a score
    intraclass correlation of 0.5. These are illustrative assumptions, not MARISMa estimates.

| Null scenario | Resistant / susceptible | Bootstrap tail, unstratified | Bootstrap tail, stratified | Mann–Whitney | Brunner–Munzel | DeLong z |
|---|---|---|---|---|---|---|
| identical | 50 / 50 | 0.0220 | 0.0220 | 0.0213 | 0.0215 | 0.0230 |
| identical | 50 / 200 | 0.0250 | 0.0200 | 0.0270 | 0.0285 | 0.0295 |
| identical | 100 / 400 | **0.0400** | **0.0370** | 0.0262 | 0.0260 | 0.0283 |
| heavy ties | 50 / 50 | 0.0220 | 0.0250 | 0.0222 | 0.0243 | 0.0255 |
| heavy ties | 50 / 200 | 0.0290 | 0.0290 | 0.0278 | 0.0278 | 0.0300 |
| heavy ties | 100 / 400 | 0.0280 | 0.0290 | 0.0240 | 0.0253 | 0.0260 |
| unequal spread | 50 / 50 | 0.0360 | 0.0330 | 0.0350 | 0.0310 | 0.0323 |
| unequal spread | 50 / 200 | 0.0260 | 0.0290 | **0.0495** | 0.0215 | 0.0250 |
| unequal spread | 100 / 400 | 0.0310 | 0.0310 | **0.0630** | 0.0275 | 0.0293 |
| clustered | 50 / 50 | 0.0570 | 0.0560 | 0.0665 | 0.0680 | 0.0710 |
| clustered | 50 / 200 | 0.0750 | 0.0730 | 0.0612 | 0.0628 | 0.0665 |
| clustered | 100 / 400 | 0.0610 | 0.0640 | 0.0648 | 0.0658 | 0.0665 |

**What the check shows:**
- **The bootstrap tail is liberal.** It rejected 0.0370–0.0400 at 100 / 400 with identical score distributions,
  beyond Monte Carlo error. A change is warranted.
- **Mann–Whitney tests a different null.** It is calibrated only when both classes share one score distribution (ties
  included). With unequal spread and AUROC 0.5 it rejected up to 0.0630, because it tests equality of distributions,
  not AUROC = 0.5 (Fay & Proschan 2010).
- **Brunner–Munzel stays close to nominal.** It stayed between 0.0215 and 0.0310 in all three scenarios with
  independent isolates. It targets AUROC = 0.5 without assuming equal distributions (Brunner & Munzel 2000). DeLong's
  z behaved similarly, but was slightly more liberal (up to 0.0323).
- **Clustering defeats every isolate-level test.** Under clustering they all rejected 0.0560–0.0750, more than twice
  the nominal level.

**Proposed procedure (exact)**, for each antibiotic:
1. **Estimand.** θ = P(S_R > S_S) + ½ P(S_R = S_S), the AUROC with ties counted one half (Bamber 1975). S is the frozen
   model's probability, S_R for a resistant isolate and S_S for a susceptible one, both from the antibiotic's cohort.
2. **Test.** A one-sided Brunner–Munzel test of H0: θ ≤ 0.5 against H1: θ > 0.5 (Brunner & Munzel 2000), with
   mid-ranks for ties and a t approximation with Satterthwaite degrees of freedom.
   - In the locked environment (scipy 1.18.1) this is
     `scipy.stats.brunnermunzel(resistant_scores, susceptible_scores, alternative="greater", distribution="t")`.
   - Before scoring, a test confirms on synthetic data that this call rejects when resistant scores tend to be larger.
     The simulation script already makes that check.
3. **Degenerate data.** If the Brunner–Munzel statistic is not finite (a zero variance estimate, as with complete
   separation or all scores tied), p comes from 100,000 Monte Carlo permutations of the class labels, with AUROC as
   the statistic and seed 42: p = (1 + b) / (m + 1) (Phipson & Smyth 2010). This fallback is for degenerate data only.
4. **Multiplicity.** Holm (1979) over the fixed family {ciprofloxacin, ceftriaxone}.
   - With p(1) ≤ p(2): H(1) is rejected if p(1) ≤ 0.025, and only then is H(2) rejected if p(2) ≤ 0.05.
   - Adjusted p-values: p̃(1) = min(1, 2·p(1)) and p̃(2) = max(p̃(1), p(2)).
   - "Ranking transfers to MARISMa" may be said for an antibiotic only if its hypothesis is rejected.
   - An antibiotic dropped (A6) or below the minimums (A4) enters with p = 1.
5. **Interval.** The AUROC's 95 % interval is the percentile interval of 2,000 stratified bootstrap resamples (seed 42):
   resistant and susceptible isolates are resampled separately, each to its own count.
   - The interval is descriptive. The claim rests on the test alone, because the simulation suggests a percentile tail
     can be liberal at larger counts.
   - Stratification makes single-class resamples impossible.
   - The gap's external side uses the same stratified resampling; its internal side stays as in endpoint 2.
6. **Undefined metrics.**
   - A metric undefined in a resample (precision with nothing flagged, NPV with an empty zone, a calibration slope
     with constant scores) is left out of that metric's interval for that resample, and counted.
   - If more than 1 % of the 2,000 resamples (more than 20) are undefined, the metric's interval is "not estimable".
   - A metric undefined on the full cohort is "not estimable".
   - The 1 % is a project quality-control choice.
   - Subgroups lacking either class are "not estimable", and no subgroup gets a p-value.
7. **Linkage robustness (descriptive).** For each antibiotic, the Brunner–Munzel statistic is also reported with its
   variance doubled, and with the resulting one-sided p. The doubling is an assumed design effect of 2 for repeat
   isolates per patient, not an estimate from MARISMa. It changes no decision; it shows how fragile a rejection is to
   within-patient dependence of that size.

**Assumptions, and the limitation from missing patient linkage.** Every isolate-level procedure assumes independent
isolates. Without patient identifiers, MARISMa may contain several isolates from one patient, with the same resistance
status and similar spectra. Under the simulated clustering, false rejections were more than twice the nominal rate. The
Holm-controlled error rate therefore holds only if the isolates are approximately independent, and any claim that
ranking transfers must be reported with this limitation.

**Comparability with earlier versions:**
- Version 0.8's rule corresponds to "the point estimate meets 0.95".
- Version 0.7's transfer criterion corresponds to "the point estimate meets 0.95, or the interval contains 0.95".
- Both readings are reported. Neither is called "met", "held" or "reliable".

**Empty zone.** If no isolate falls in the zone, coverage is 0 and NPV is "not estimable". Resamples with an empty zone
follow A3, item 6.

**Not clinical.** 0.95 is a research criterion. Neither historical reading, and no result here, establishes clinical
reliability.

### A6. Operational rules

**Supersedes,** where they conflict: the cohort's replicate rule, step 2's dropping rule, and step 3's checks.

1. **A dropped antibiotic.** An antibiotic dropped at step 2 (fewer than 100 cohort isolates with a non-missing
   interpretation) contributes p = 1 to the fixed two-hypothesis Holm family. If both antibiotics are dropped, nothing
   is scored, and the study stops and is reported.
2. **Replicates.**
   - For each isolate, biological-replicate folders are examined in ascending order, and within each, technical-replicate
     folders in ascending order.
   - Folder names are ordered numerically when all of them are integers; otherwise by Unicode code point.
   - The first spectrum that passes the reader's checks is used. If none passes, the isolate is excluded and counted.
3. **A systematic error stops processing before labels, whatever the failure percentage.** Evidence of a systematic
   reader or calibration error includes:
   - a failing reader test;
   - failures that share a cause in the reader or the calibration, beyond an isolated corrupt file: a calibration
     field missing or out of range across spectra, an m/z axis that is not strictly increasing, or a mass range that
     does not cover 2,000–20,000 Da;
   - failures concentrated in one acquisition batch (a year folder, acquisition date or instrument);
   - on review, an artefact in spectra that pass the checks.

   Processing then stops, no label is read, and continuing requires a dated amendment.
4. **Aggregate pause.** This is a project quality-control choice, not a scientific standard.
   - **Denominator:** the *E. coli* isolates that satisfy the species, year and sample-source rules and have at least
     one replicate folder.
   - **Numerator:** those excluded because no replicate passes the reader's checks.
   - **The pause:** if the numerator exceeds 5 % of the denominator, processing pauses before any label is read. Failure
     reasons are reviewed by batch, without outcome access.
   - **After the pause:** the review ends either in a stop (item 3) or in a dated owner decision to continue. Nothing
     resumes automatically, and no check is loosened.
   - **Why 5 %:**
     - In this project's earlier builds, processing failures were 0.44 % for the DRIAMS-A cohorts (19 of 4,278 and 19
       of 4,302) and 1.98 % for the V1.4 screening build (10 of 505).
     - Unreadable files alone were 0.19 % and 0.59 %.
     - 5 % is about 2.5 times the highest rate, so ordinary file-level failures should not trigger it, while a failure
       affecting one isolate in twenty is reviewed.

### B2. A non-finite primary test is "not estimable"; there is no fallback test

**Supersedes:**
- A3, item 3 (the 100,000 Monte Carlo label permutations for degenerate data);
- A7, row 8's "degenerate fallback".

**The rule:**
- If the Brunner–Munzel statistic or its p-value is not finite, the primary test for that antibiotic is reported as
  **"not estimable"**. The antibiotic then enters the fixed Holm family with p = 1.
- No permutation test, and no other fallback test, is run.
- Descriptive metrics (the AUROC, PR-AUC and the other endpoints) are still reported wherever they are defined.

**When it applies.** In the locked environment (scipy 1.18.1), synthetic probes give a non-finite p-value for:
- complete separation, in either direction;
- all scores tied;
- each class holding a single constant score;
- a class with one isolate.

The AUROC stays defined in every one of these cases. **One consequence:** a model that separates the classes perfectly
(AUROC 1.0) gets a "not estimable" primary test, and so no claim. This rule accepts that conservatism. With at least 50
isolates per class, it is unlikely to arise.

**Implementation, before approval.** The rule is implemented as `src/primary_endpoint.py`, which is pure functions with
no input or output. It is tested on synthetic scores in `tests/test_primary_endpoint.py`. Both were written at the
owner's instruction of 2026-10-03, before approval. Like the simulation script, they read no data. Step 0's "before any
Version 2.0 code" is superseded to that extent only.

**A note on the sign.** scipy reports a negative statistic when resistant scores tend to be larger. The decision uses
the p-value of `alternative="greater"`, with the resistant isolates' scores as the first sample. Its direction is
tested.
