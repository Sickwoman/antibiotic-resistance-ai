## What this contains

come after the Version 2.0 closure, `6c15f29`.

- **`demo/`:** `python -m demo` serves one page on 127.0.0.1:8050 (FastAPI), outside `src/api/`.

## Verification, and where each check ran

- **CI** (Ubuntu and Windows, Python 3.11 and 3.12) runs the unit tests from a fresh install of `requirements.txt`.
  It has no model bundle and no browser.
- **End to end,** on one Windows 11 machine with the bundle and Microsoft Edge (`docs/demo/verification.md`):
  - **Scores:** the displayed scores equal the frozen model's in-process output and the unchanged API's.
  - **Failures:** a missing bundle, a damaged bundle, a refused spectrum and a timeout end in coded errors.
  - **A fresh clone without the bundle** serves the page and the evidence, and explains how to obtain and verify
    the bundle.
  - **Network and storage, observed at runtime in that environment:**
    - loopback-only sockets and page requests;
    - no browser TCP beyond 127.0.0.1, and no UDP data;
    - only temporary spectra written, all deleted;
    - no browser storage.

  These are observations, not guarantees for other environments.

## Known limitations

- **The frozen bundle is not distributed.**
  - A fresh clone cannot make predictions until the project owner supplies the bundle through a trusted channel.
  - The user must check its SHA-256 against the published `d59d6d7d…` value. A matching sidecar alone does not
    establish trust: joblib files are pickles.
- **A temporary spectrum can survive a killed server** until the next start (folders older than 15 minutes are swept).
- **Localhost only,** with no authentication.
- **The browser check needs Edge on Windows.**
