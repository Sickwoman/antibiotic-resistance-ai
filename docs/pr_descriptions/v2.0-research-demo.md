## What this contains

### The research demo (`demo/`)
`python -m demo` serves one page on 127.0.0.1:8050. It is a FastAPI app outside `src/api/`, which it neither imports
nor changes.
- **Inputs:** three synthetic spectra (seed 42). They were committed (`3ae0e49`) before the model scored any of them,
  and carry no label.
- **Inference:** "Run research prediction" runs the unchanged `scripts/predict_spectrum.py` in a subprocess.
- **Display:** the score, the frozen threshold, and "above" or "below the research threshold". Never "Resistant",
  "Susceptible", a zone label, a treatment, or green.
- **Evidence panel:** read at runtime from the committed Version 2.0 aggregates.
- **Safeguards:** no upload route, a strict CSP, loopback Host names only, `Cache-Control: no-store`, no browser
  storage. One temporary spectrum per run, deleted when the CLI returns.
- **Docs:** `demo/README.md` covers fresh-machine setup, the frozen model, launch, troubleshooting and the evidence.
